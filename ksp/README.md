# Как запускать скрипты полёта

Все файлы лежат в одной папке: `burn.py`, `ascent.py`, `mun_transfer.py`,
`mun_capture.py`, `mun_impact.py`, `telemetry.py`, `plot_flight.py`.
Команды вводятся в командной строке, открытой в этой папке
(в проводнике: правый клик по папке → «Открыть в терминале»).

## Один раз перед полётом

1. KSP запущен, ракета стоит на старте, в окне kRPC нажата **Start server**.
2. Включи запись экрана: **Win + Alt + R** (видео попадёт в «Видео → Клипы»).
3. Второе окно терминала: `py telemetry.py flight.csv` → в игре **Allow**.

## Полёт: четыре команды подряд

| Шаг | Команда | Что делает | Когда готово |
| --- | --- | --- | --- |
| 1 | `py ascent.py` | Взлёт, разворот на восток, сброс ступеней и обтекателя, круговая орбита 80 км | Печатает «Орбита: Ap … Pe …» |
| 2 | `py mun_transfer.py` | Ищет момент разгона к Муне, ставит узел ~840 м/с и выполняет | Печатает «Летим к Муне: перицентр … км» |
| 3 | `py mun_capture.py` | Коррекция на полпути (полярный пролёт на 100 км), ожидание входа в зону Муны, торможение в орбиту | Печатает «Полярная орбита Муны готова» |
| 4 | `py mun_impact.py` | Узел схода с орбиты; ждёт Enter (можно передвинуть узел в кратер); падение | Окно «Результаты полёта» в игре |

После каждого шага: **F5** в игре и **F1** для скрина. При первом запуске
каждый скрипт нужно принимать в игре кнопкой **Allow**.

Когда появится окно «Результаты полёта», останови запись экрана
(**Win + Alt + R**) и телеметрию (Ctrl+C в её окне), затем
`py plot_flight.py flight.csv` нарисует графики.

## Если что-то пошло не так

| Что видишь | Что делать |
| --- | --- |
| `ModuleNotFoundError: No module named 'krpc'` | `pip install krpc` |
| `ConnectionRefusedError` | В игре не запущен сервер kRPC: нажми Start server |
| Скрипт пишет «Нет тяги» и останавливается | Этап с двигателем не активен: нажми пробел в игре и запусти скрипт снова |
| «Встречу с Муной найти не удалось» | Орбита сильно наклонена. Нажми F9 и перелети ascent.py заново |
| Ракета крутится и не успокаивается | В игре включи SAS (T), дай ей замереть и запусти скрипт снова |
| Любая другая ошибка красным текстом | Нажми F9 и запусти шаг заново |

Во время видео ничего не трогай в игре, кроме Enter для mun_impact.py.
Если хочешь кадры без панелей, нажми F2 (второй раз возвращает панели).
